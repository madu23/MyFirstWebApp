My Web Development Journey

Learning how HTML structure, styling, accessibility, and usability contribute to creating effective web applications.

Why I Am Learning HTML Styling

I have become more interested in web development because it combines design, structure, and problem-solving. Learning HTML has helped me understand how information can be organised clearly and how pages can become more engaging for users.

During this module, I have explored how headings, paragraphs, links, images, and inline styling can improve both presentation and usability. I now understand that a good webpage is not only readable but also accessible and easy to navigate.

HTML Styling and Formatting

I have learnt how to use different font styles, sizes and colours to make content clearer and more visually appealing.

Using HTML attributes such as style, font-size, and color has helped me see how small changes can improve the user experience. I also learned the difference between using the <br> tag for a line break and the <pre> element to preserve text spacing.

Accessibility and Usability

One of the most useful lessons from the weekly learning outcomes is that accessibility should be considered throughout the design process. A page should be easy to read, easy to understand, and easy to navigate for different users.

I have learned that good design goes beyond appearance. It includes clear headings, logical structure, meaningful text, and accessible content that supports users with different needs. This connects directly to the module learning outcomes around usability and accessibility.

What I Want to Learn Next

My next step is to build on these skills by learning CSS, as this will allow me to improve layout, spacing, colour and responsiveness. I also want to continue developing accessible design choices so my webpages are functional, clear, and user-friendly.

Overall aim: create web applications that are not only visually appealing but also accessible, usable and effective for a wide range of users.
