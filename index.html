My Web Development Journey

A little about my interest in creating for the web.

Why I Am Learning HTML

I am interested in web development because it combines creativity with problem-solving. HTML is a useful starting point because it gives a webpage its structure and meaning.

As I learn, I want to understand how headings, paragraphs, links, and other elements work together to make information clear and easy to explore.

What I Want to Explore Next

My next step is to practise building pages with a logical structure, then learn how CSS can improve their appearance and how JavaScript can add interaction.

My goal: create webpages that are useful, accessible, and enjoyable to read.

Resources

I am using the W3Schools HTML tutorial to review HTML elements, attributes, headings, and paragraphs.
